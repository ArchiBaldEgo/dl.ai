It feeds the LEFT navigation sidebar (#nav-sidebar, rendered by admin/nav_sidebar.html on every admin page). Everything renders in ONE unified style (по ТЗ «всё в одном стиле»): each app — real model apps («Раздел ИИ») and the AI tool groups injected by AIAdminSite.each_context — is an .ai-nav-group: quiet uppercase title, then an iconised link list (.ai-nav-item). Tool groups carry app_label `ai-tools-*` and come first (tools_apps + real_apps, see site.py::each_context), real apps follow. Model rows keep a small «+» add-action when add_url is present (stock addlink capability), and the current page highlights via current-app/current-model (substring check, same semantics as the stock template). The stock nav quick-filter JS only knows `th[scope=row] a` table rows — there are none here — so static/admin/js/ai_nav_filter.js filters .ai-nav-item rows and manages the stock `.no-results` flag on the input.
