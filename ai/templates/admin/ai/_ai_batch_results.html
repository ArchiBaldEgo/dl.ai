{% comment %} Общий partial мини-таблицы результатов batch-solve. Используется страницей /arm/solve/ (arm_solve.html), «Настройкой ИИ-приложения» (aiappsettings_change_form.html), страницей «Закреплённые пакетные решения» (pinned_runs.html) и детальной страницей записи Журнала запросов в режиме «Пакетное решение» (request_logs_detail.html), чтобы рендеринг был идентичен. Единый источник правды — window.ArmBatchResults. Экспорт XLSX — серверный (ai/admin/export.py), кнопка здесь — ссылка на эндпоинт по run_id. Переключатель «Все / Не пройденные» в шапке карточки «Ответы моделей» (счётчики, авто-раскрытие не пройденных, режим в localStorage) живёт там же — его получают все поверхности, где рендерится эта таблица. CSS и JS вынесены в отдельные файлы и подключаются ГЛОБАЛЬНО: - static/admin/ai/batch_results/index.css → {% block extrastyle %} - static/admin/ai/batch_results/index.js → {% block extrahead %} оба в ai/templates/admin/base_site.html. Так window.ArmBatchResults определён ДО любых вызывающих скриптов страницы, а сам partial остаётся чистым контейнером без инлайн-кода (его подключают четыре страницы — дублировать теги в каждой было бы копипастой). NB: комментарии с решёткой Django вырезает только в одну строку — многострочный комментарий шаблона обязан быть блочным тегом comment. {% endcomment %}
