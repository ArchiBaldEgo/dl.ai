Тема

Тема подставляется в препромпт. По умолчанию препромпт берётся из «Препромптов по умолчанию» (привязка язык+тема, Инструменты → Препромпты по умолчанию); можно выбрать и вручную — в поле ниже.

Препромпт

По умолчанию — привязка «препромпта по умолчанию» для выбранного языка и темы (точная, иначе привязка «на весь язык»). Вместо неё можно выбрать любой препромпт вручную.
