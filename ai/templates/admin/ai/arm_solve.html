Тема

Тема подставляется в промпт. По умолчанию промпт берётся из «Промптов по умолчанию» (привязка язык+тема, Инструменты → Промпты по умолчанию); можно выбрать и вручную — в поле ниже.

Промпт

По умолчанию — привязка «промпта по умолчанию» для выбранного языка и темы (точная, иначе привязка «на весь язык»). Вместо неё можно выбрать любой промпт вручную.

Попыток на пару

Включая первую попытку. После каждой неудачи DL промпт дописывается и задача решается заново; правки сохраняются только если пара в итоге прошла. Затем все пары решаются ещё раз по итоговым промптам (проверка). 0 — без ограничения: задача решается, пока не получится, либо пока вы не нажмёте «Далее» в списке процессов (тогда пара пропускается, правки не сохраняются).

Правятся только промпты, на которые у вас есть права (свои, либо ключ «Перезаписывать чужие промпты»). Пары с чужими промптами пропускаются. Промпт «по привязке» (по умолчанию) остаётся тем же и накапливает правки.
