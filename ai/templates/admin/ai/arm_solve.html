Язык / расширение для тестирования

DL REST send-solution требует расширение файла. Курс может содержать задачи разных языков (например «[Ассемблер i8086, C-MPA]» — каждая задача допускает и .i86, и .mpc), поэтому выберите нужный вручную. Препромт выбирается после расширения — для каждого расширения свой список.

Препромпт

Сначала выберите расширение выше — для каждого расширения свой список препромтов. Отправка без препромта невозможна.
