Переменные, которые задаются глобально, должны соответствовать количеству и названию в "Формат ввода".

Пример:
x: -4 -6 0 -10 3 7 3 6 0 -5
Массив в этом примере называется x. В других задачах он/они называется/ются подругому.
a: 5
b = 3
и тд.


Переменные, где хранится ответ, должна соответсвовать количеству и названию в "Формат вывода".

Пример:
res: 19
Переменная этом примере называется res. В других задачах она/они называется/ются подругому.
res1: 13
res2 = 16
и тд.


Все входные переменные в "Формат ввода", должны быть с __in. Так же указывать размерность и типизацию. 

Пример:
int __in __bits(n) g;
int - тип данных
__in - обозначение входных данных
__bits(n) - размерность в байтах, где n - это количество (8/16/)
g - название переменной


Все входные переменные в "Формат вывода", должны быть с __out. Так же указывать размерность и типизацию. 

Пример:
int __out __bits(n) c;
int - тип данных
__out - обозначение выходных данных
__bits(n) - размерность в байтах, где n - это количество (8/16/)
с - название переменной


ОБЯЗАТЕЛЬНО!!!
При объявления массива (x[n]), __in и __out, не задается. 
Любой массив должен быть int.
Как понять, что это массив? После название переменной будут квадратные скобки [].

Пример:
int __bits(n) x[m];
int - тип данных
__bites(n) - размерность в байтах, где n - это количество (8/16/)
x - название массива
m - количество элементов в массиве

__in не должно быть при объявлении массива, так как при объявлении массива недопустимы такие модификаторы, как __in и __out.

НЕПРАВИЛЬНЫЙ пример:
int __in __bits(8) x[m]; // __in тут не нужен, это грубая ошибка.


Глобальные переменные должны быть только те, которые есть в "Формат ввода" и "Формат вывода".
Остальные переменные, которых нет явно в задаче, их объявлять локально в main().

Пример:
int __in __bits(n) a; // это данно по условию
int __in __bits(n) b; // это данно по условиб

void main(){
    int __in __bits(n) x; // вспомогательная переменная
    int __in __bits(n) y; // вспомогательная переменная
}


Чтение переменных проводить не нужно.
Присвоение значений в глобальных переменных нужно исключить.
